Step 7 of 8
Pause & resume (0% idle CPU)
When agents are idle waiting for human input, Substrate checkpoints their memory to disk to save 90% compute, waking them in under 200ms.
▼ Show the real command
atectl actor suspend my-first-actor && atectl actor resume my-first-actor

✓ Suspending idle actor memory state to disk (38ms, CPU drops to 0%)
✓ Request parking held incoming user message in queue
✓ Restoring actor memory state on wake event in 115ms
Done
Sub-200ms instant resume confirmed! Finally, let's scale your fleet.
